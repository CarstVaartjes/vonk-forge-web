# Contributing

Thank you for helping improve [`vonkforge.ai`](https://vonkforge.ai).

- **Report a problem with the site:** open a bug report issue with the page
  URL and what you saw.
- **Propose a change:** follow [Run the frontend](README.md#run-the-frontend)
  and [Checks](README.md#checks), then open a pull request against `main`.
  [AGENTS.md](AGENTS.md) holds the working agreement and the gates CI runs.
- **Report a security problem:** see [SECURITY.md](SECURITY.md); never in a
  public issue.

Recipe content comes from
[vonk-forge-recipes](https://github.com/CarstVaartjes/vonk-forge-recipes) and
the Controller from [vonk-forge](https://github.com/CarstVaartjes/vonk-forge);
change them there.

## Release notes

The site has no versioned releases and no changelog. It deploys from `main`,
and the merged pull requests are the history of changes.

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
